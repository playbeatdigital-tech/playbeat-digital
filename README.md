- **Icons & Badges**: Font Awesome 6.5.1
- **Deployment & Hosting**: Vercel Serverless Edge Platform

## 💻 Local Development

1. **Clone the repository**:
   ```bash
   git clone https://github.com/playbeatdigital-tech/playbeat-digital.git
   cd playbeat-digital
   ```

2. **Serve locally**:
   ```bash
   # Using Python
   python -m http.server 3000

   # Or using Node.js
   npx serve .
   ```

3. Open `http://localhost:3000` in your browser.
